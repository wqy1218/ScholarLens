# ScholarLens 使用说明

论文阅读工作台，Windows 单机应用。数据存在本机一个 SQLite 文件里。

## 一、环境要求

| 项目 | 要求 |
|---|---|
| 操作系统 | Windows 10 / 11，64 位 |
| 磁盘 | 约 2 GB |
| 内存 | 4 GB 及以上 |

已内置 Python 运行时与本地嵌入模型，不需要另装 Python / Node.js，也不需要下载模型。
联网只用在两处：从 arXiv 下载论文、调用你配置的大模型 API。

## 二、安装

1. 双击 `ScholarLens-Setup-1.1.0.exe`；
2. SmartScreen 提示时点「更多信息」→「仍要运行」；
3. 安装范围选「仅为当前用户安装」，安装位置可自选，默认 `%LOCALAPPDATA%\Programs\ScholarLens`；
4. 完成后自动启动，首次启动约 5–15 秒。

静默安装：`ScholarLens-Setup-1.1.0.exe /S /D=D:\Apps\ScholarLens`（`/D=` 放最后，路径不加引号）。

## 三、配置模型 API

「设置」→「API」→ 填 API Base、API Key、快速模型、深度模型 →「保存全部」，即时生效。
多家服务商可点「新增档案」，在档案列表切换。

未配置 Key 可用：导入、解析、领域归属、领域发现、手动高亮、批注、笔记、图谱、全文搜索。
未配置 Key 不可用：摘要、解释、翻译、问答、自动高亮、图片提问、扫描版 PDF 的文字识别。

## 四、使用

**领域**：左栏「+ 领域」新建；「领域发现」给出聚类候选，勾选后「应用」只新增归属，不改已有主领域。
领域可拖成子领域，「↥」移回顶层；★/◈/○ 是主攻 / 交叉 / 了解，参与跨领域问答排序。

**导入**：首页「导入论文」支持 arXiv 链接或 ID（可多行）、本地 PDF 多选、关键词批量搜索导入。
PDF 会复制一份到数据目录。扫描版 PDF 解析时自动尝试文字识别（需 Key，最多 12 页）。

**阅读**：打开论文后右侧是摘要、高亮、问答、笔记四个标签页。
划选一句弹出菜单：翻译 / 解释 / 加高亮 / 批注。高亮三类——背景蓝、解决思路绿、局限红，点行号跳回原文。
批注可打标签（问题 / 方法 / 结论 / 局限 / 想法）。工具栏：跳读、结构、卡片、导出、缩放、翻页；
`PageUp` / `PageDown` 翻页，`Ctrl+K` 命令面板。

**问答**：单论文在「问答」标签，Enter 发送，可「📷 图片」框选截图提问；
页面底部输入框是跨论文提问，以 `@` 开头进入比较会话。每次提问显示「范围：…」标签，点开可改范围后重问；
跨领域检索超时或失败的领域会标注「证据不完整」。

**领域沉淀**：领域行的「知」是知识沉淀视图（摘要、高亮、笔记、未决问题、待复核引用、术语），
「问」是领域问答窗口；「知」内可切到图谱，线宽=关联强度，绿线=引用，双击节点跳转论文。

**其他**：右上角有审计、布局（面板拖乱后恢复）、明暗主题、设置；
关闭按钮默认询问最小化到托盘还是退出，彻底退出用托盘右键「退出」。

## 五、数据位置

```
%APPDATA%\ScholarLens\data\
├─ scholarlens.db      论文库、领域、笔记、问答、引用、翻译缓存
├─ papers\             PDF 副本
├─ llm_cache.db        模型响应缓存
├─ electron-profile\   窗口与界面状态
├─ indexes\            物化索引
└─ backend.lock        运行期锁文件
```

## 六、备份 / 升级 / 卸载

备份：托盘右键「退出」，复制整个 `%APPDATA%\ScholarLens\data`。
升级：运行新版安装包，选同一个安装目录；数据在 `%APPDATA%`，不会被删除。
换机：把备份的 `data` 覆盖到新机器的同一路径。
卸载：「设置 → 应用 → ScholarLens → 卸载」，删除安装目录，保留数据目录。

## 七、常见问题

| 现象 | 处理 |
|---|---|
| 摘要 / 问答失败 | 检查「设置 → API」的 Base、Key、模型名与账户余额 |
| 首次摘要或问答慢 | 模型加载 15–20 秒 |
| 解析停在 0% | 单篇最长 2–3 分钟；可「取消解析」后点「重试」 |
| 扫描版 PDF 没有文字 | 确认已配置 Key；最多处理前 12 个无文字页 |
| 后端启动失败 | 把安装目录加入安全软件白名单 |
| 论文打开失败 | 点该论文的「重试」；仍失败则更换 PDF |
| 界面错乱 / 面板丢失 | 右上角「布局」恢复 |
| 端口被占用 | 自动在 21800–21849 之间换端口 |
